# Shreedha Enterprises Website

Static responsive website built with:
- HTML5
- Tailwind CSS via CDN
- Modern ES6+ JavaScript
- Responsive mobile navigation
- Smooth scrolling
- Contact form demo
- Shreedha Enterprises logo asset

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.
